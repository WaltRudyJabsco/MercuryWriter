# 6.7.6 · CANONICAL EDGE

6.7.6 makes evidence authority turn-local. A failed live edge may explain one failed invocation; it may not become a conversational law that contaminates later unrelated questions. Stable history, explanations, recipes, and ordinary knowledge remain ordinary cognition unless the operator explicitly asks for verification.

Home clarification is transactional: a place supplied as the answer to `What city should I use for home?` is tentative until the canonical place/weather edge validates it. Explicit declarations such as `my home is Portland Oregon` remain synchronous operator-owned teaching.

Simple current time/date questions terminate directly at the trusted host clock rather than asking a language model to reinterpret an already authoritative temporal receipt.
