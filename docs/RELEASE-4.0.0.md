# 4.0.0 — Unified Node foundation

- Preserves the 3.3.11 LOOK/Future Crash milestone.
- Includes Signal Window 0.5.2 and Local Labs Host 0.5.1 source in the one distribution.
- Adds the cross-platform Unified Node daemon and one top-level installer.
- Adds capability and peer discovery plus a shared request/activity supervisor.
- Signal now claims the shared interactive lane and publishes planning/visual phases.
- Linux persistence uses systemd; macOS persistence uses launchd; core node code is platform-neutral Python stdlib.
- No visual redesign and no new model dependency.
