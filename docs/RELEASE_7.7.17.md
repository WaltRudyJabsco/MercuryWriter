# Future Crash + LOOK 7.7.17 — Albert Media Path

Albert catalog playback now follows Signal's proven browser lifecycle: Ask returns durable Fabric media identity, the browser requests a short-lived ticket at playback time, then assigns the ticketed Range-capable URL to the media element. This removes the pre-minted URL from the Ask response while preserving the existing Fabric item proxy and all native media paths.

No changes were made to LOOK/mpv playback, `/v1/media/item`, MM/MN/MP, Signal browser media, All Classical, or Classic Arts.
