# 3.3.8 — Referential Turn Isolation

- Explicit resources suppress stale cross-session prose for the current resource task.
- Resource handles carry cheap session recency for `it` / `this` / `that` resolution.
- `open it in the browser` routes through a typed host action instead of model-authored shell commands.
- Document continuation recovery re-anchors the actual latest user task and forbids importing historical subjects.
- Resource persistence remains separate from per-turn evidence and action state.
