# 7.5.0 — ALBERT TRUST

Albert becomes a persistent graphical face for the shared LO/Fabric cognition contract rather than a browser-local chat session.

- Server-owned `main` thread persists across browser views and Albert restarts.
- Opening Albert restores the active thread; the old mandatory “Albert is awake” fold is gone.
- Cognition receipts/provenance become explicit evidence badges. MODEL/INFER evidence is never marked verified.
- The response envelope supports typed clarification choices for one-click follow-up without inventing action success.
- Albert renders a quiet deterministic Signal expression for cognition answers. Signal is explicitly presentation, never evidence.
- Existing plain-text Albert clients remain compatible; richer fields are additive.

Maps/places are intentionally not part of this release. They should arrive as a renderer for a typed place result after the trust envelope is established.
