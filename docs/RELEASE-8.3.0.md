# 8.3.1 — LIVING FABRIC

- Media Find defaults to logical media: equivalent physical sources collapse into one row while provenance remains intact.
- `V` toggles all physical sources; `H` toggles hidden media; `X` hides selected paths; `D` hides selected source trees.
- Hidden catalog knowledge is preserved across scans and omitted from normal browsing/playback surfaces.
- Media Info lists physical source count and paths for collapsed duplicates.
- Chess and Checkers use large terminal sprites with blue/red sides; game engines and GTNW behavior remain unchanged.
- Dash Mini restores date/time and core health/media truth, trims RECENT to two events, and adds an event-reactive ASCII Signal vocabulary.
