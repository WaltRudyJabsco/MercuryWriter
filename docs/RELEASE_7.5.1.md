# 7.5.1 — ALBERT SOURCES

- Saved Albert folds are durable server-owned objects across browsers.
- Saved objects can be renamed, deleted, and pinned; pin is presentation state, not a second object type.
- Dynamic saved requests retain their prompt and refresh when reopened.
- PLACES is a provider-neutral typed result; first provider is OpenStreetMap Nominatim.
- Albert renders sourced coordinates as a calm line/coordinate map and labels them with PLACES · VERIFIED.
- Signal remains expressive and explicitly non-evidentiary.
