# 7.5.0 — OBSERVATION PLANE

Future Crash + LOOK now maintains present-tense state from a read-only observation plane as well as authoritative action receipts. Observation, capability, judgment, policy, action and memory remain separate layers. Current windows can be enumerated and reconciled where the host OS exposes them; state queries are first-class JEV operations; relational selectors operate over live object sets; stale state expires instead of silently becoming memory.
