## Bundled

- Inspect existing files before modifying them.
- Prefer surgical edits over rewrites of working systems.
- Preserve unrelated behavior during modifications.
- Test changes when a practical test is available.
- Distinguish dependency failure from project failure.
- Treat user-owned shell configuration conservatively.
- Prefer canonical install locations over scattered files.
- Make optional infrastructure fail softly when the core can still work.
- Use structure when it improves readability; do not add machinery merely to describe machinery.
